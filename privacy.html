Политика конфиденциальности приложения «Claude Gmail»

Дата: 27.10.2026. Владелец и единственный пользователь приложения — Алексей Вокин, alex.vokin@gmail.com.

1. Что делает приложение

Приложение даёт ИИ-ассистенту, запущенному на компьютерах владельца, доступ к его собственным Gmail, Google Календарю и Google Диску: читать и искать письма, создавать черновики и отправлять письма по команде владельца, работать с событиями календаря и файлами Диска.

2. Чьи данные обрабатываются

Только данные аккаунта владельца. Приложение не предназначено для других пользователей и не запрашивает доступ к чужим аккаунтам.

3. Хранение и передача

Токены доступа Google хранятся только на компьютерах владельца. Данные из Google не продаются, не передаются третьим лицам и не используются для рекламы. Содержимое писем и файлов обрабатывается только для выполнения задач владельца.

4. Использование данных Google

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

5. Отзыв доступа

Доступ можно отозвать в любой момент: myaccount.google.com → Безопасность → Сторонние приложения с доступом к аккаунту.
